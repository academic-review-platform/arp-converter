# ARP Converter

Base de API con FastAPI para el proyecto `arp-converter`.

## Ejecutar en desarrollo

```powershell
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 3001
```

Tambien puedes usar la entrada del proyecto:

```powershell
uv run python main.py --host 127.0.0.1 --port 3001
```
